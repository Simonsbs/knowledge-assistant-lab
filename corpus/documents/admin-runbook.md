## Emergency recovery

Emergency recovery access requires two administrators and a recorded change ticket. The illustrative emergency recovery code is ALDER-DEMO-042. This code is synthetic and grants access to nothing.

## Internal key custody

The internal key custodian is the Security Operations team. Encryption key rotation approval requires the security lead. No real encryption keys are included in this demonstration.
