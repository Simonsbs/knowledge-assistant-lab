# Knowledge lab validation

Validated locally on 11 November 2026. The implementation is at `/#/labs/knowledge`. It has not been deployed.

## Automated checks

`npm run build` passes TypeScript, the existing portfolio content checks, source-ingestion integrity, recorded-report integrity, all 12 Node lab tests and the Vite production build.

The optional Python environment passes all 18 service tests:

```powershell
.\.venv-knowledge\Scripts\python.exe -m unittest discover -s labs\knowledge-assistant\tests -p 'test_*.py' -v
```

Two of those tests use the real LangChain ChatOllama client against a mock Ollama HTTP endpoint. They check the transport, model-tag health check, citation handling and returned token counts. The fixture is not a live model and provides no evidence of model answer quality.

## Browser verification

The development server on port 5173 and the compiled static preview on port 4173 were checked through the browser. The production preview passed the core evidence and conflict flows, and both homepage and selected-work cards opened the lab.

Verified behaviours:

- A citation expands its actual passage, source owner, update date, score and query coverage.
- The baseline retrieves the draft and archived P1 policies. Governed retrieval excludes both.
- Diagnostic-log contradictions remain visible at a passage limit of one.
- Missing plan prices produce an insufficient-evidence response.
- The synthetic emergency recovery record is excluded for Support and available for Administrator.
- The evaluation reruns all six configurations in the browser, displays the two failed decisions and exports six actual runs as JSON.
- Importing the public corpus succeeds. Importing `public/manifest.json` fails schema validation. The previous pack stays active after rejection.
- Custom-pack mode disables the sample evaluation labels. Restoring the sample allows question inspection again.
- The local health check reaches the Python adapter and reports that Ollama is unavailable. The compiled static preview offers no local-service connection button.
- Desktop testing at 1440 by 1000 and mobile testing at 390 by 844 showed no horizontal page overflow. The 760-pixel evaluation table scrolls inside its own region on mobile. Retrieval settings collapse on mobile.
- No browser console warnings or errors were recorded during the final checks. The viewport override was restored afterwards.

## Remaining limits

Live Ollama inference has since been tested; the [live validation report](knowledge-lab-live.md) records 26 accepted cited drafts, seven successful rejection probes and three known pipeline failures. Semantic human review remains pending. Browser roles filter a public synthetic corpus and do not provide private-data access control. The local adapter separately enforces its configured role when admitting context, but does not implement a multi-user identity system.

Preview processes were stopped after validation. Use `npm run dev` to inspect the application again, or follow the [lab setup](../../labs/knowledge-assistant/README.md) for optional local inference.
